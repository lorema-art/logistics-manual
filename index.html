3. 업무별 작업 방법

① 아침 확인 + 검수 준비 (09:00–09:10)

  1. 오늘 들어온 박스 수를 세요.
  2. 어제 미발송 건이 있는지 확인해요.
  3. 택배관리 시트에 오늘 보고 양식을 만들고, 아침 보고 칸에 3줄로 적어요. (8번 참고)
  4. 검수대 위를 완전히 비워요. (어제 물건이 남아 있으면 검수가 섞여요)
  5. 검수대에 놓을 것: 커터칼, 네임펜, 메모장
  6. 카트 1대를 검수대 옆에 둬요.
[아침보고] 11/06
- 입고 42박스 / 어제 미발송 3건
- 09:10 검수 시작, 특이사항 없음

하지 말 것

출근하자마자 CS 답장하기 (CS는 15:00에 한 번만)

② 입고 — 검수 + 입고 처리 (09:10–11:10, 100박스)

1회차 = 10박스 (약 12분) × 10회

  1. 카트에 박스 10개만 싣고 검수대로 와요. 10개 넘게 싣지 않아요. 검수대가 막혀서 오히려 느려져요.
  2. 박스 1개를 집어 겉면의 사서함번호(예: A023)와 수강생 이름을 확인해요.
  3. 박스를 열어요.
  4. 상품을 꺼내서 3가지를 촬영해요.
    • ① 수량: 시트에 적힌 수량과 같은지
    • ② 상품·옵션: 이름, 색상, 용량이 맞는지
    • ③ 상태: 파손·누액·유통기한
  5. 결과에 따라 바로 처리해요. 메모만 남기고 나중에 다시 보지 않아요.
    • 맞으면 → 그 줄 검수날짜 칸에 오늘 날짜 입력 (이걸 해야 운송장이 출력돼요)
    • 수량이 다르면 → 검수날짜는 넣고, 메모 칸에 "실제 3개(등록 5개)"처럼 적기 → 보고 목록에 추가
    • 파손·불량이면 → 불량품은 따로 빼 두기 → 메모 칸에 "파손 1개, 사진 있음" → 정상 수량만 입고 (사진은 4번에서 찍은 것 사용)
    • 시트에 입고 줄이 없으면 → 박스에 "미등록" 포스트잇 붙여 따로 빼 두기 → 보고 목록에 추가 (혼자 등록하지 않기)
  6. 확인 끝난 상품은 박스에 넣어서 사서함번호별 선반 앞에 내려놓아요. (선반 정리는 그날 업무를 다 마친 뒤에 해요)

하지 말 것

  • 박스를 한꺼번에 다 까 놓고 나중에 몰아서 입력하기
  • 수량이 안 맞는 걸 혼자 판단해서 시트 수량 고치기
  • 검수 중에 CS 보기

③ 출고 1 — 운송장 출력 (11:10–11:30 / 15:00–15:20)

  1. 배송 시트 메뉴에서 운송장출력을 눌러요. (검수날짜가 찍힌 재고만 나와요)
  2. 목록에서 출고 보류 건(취소·주소변경 메모)이 있으면 빼요.
  3. 출력해요.
  4. 출력된 송장을 사서함별로 나눠요. (송장 상품명 앞 [A001] 같은 코드 기준)
  5. A001 ~ A014 물건부터 먼저 분류해요.

④ 출고 2 — 포장 (11:30–12:00 / 13:00–15:00 / 15:20–16:50)

  1. 1건씩 포장해요.
    • ① 송장의 상품명·수량과 손에 든 상품이 맞는지 한 번 더 확인
    • ② 상품 + 완충재 → 테이프
    • ③ 송장 붙이기
  2. 다 싼 박스는 카트에 옮겨요. (★ 문을 열어 놓고 한 건씩 상품을 옮기지 않아요)
  3. 사서함번호 순서대로 시간 안에 끝내요.

속도가 안 나올 때

"저는 시간당 30건밖에 못 해요"로 끝내지 말고, 어느 단계에서 시간이 걸리는지 적어 주세요. 예: 상품 찾기, 박스 고르기, 송장 붙이기. 그 단계를 같이 고치면 돼요.

⑤ 출고 3 — 출고 처리 (포장 끝난 직후)

  1. 송장번호를 송장매칭 시트에 붙여넣고 송장매칭을 실행해요. → 발송완료 + 재고 출고가 같이 기록돼요.
  2. 재고가 안 맞거나 프로그램 오류로 나온 오류 송장은 따로 분류해서 먼저 보고해요.
  3. 포장이 끝나고 나면 그 문제의 상세 내용을 확인해요.

⑥ CS (15:00, 하루 한 번 · 약 20건 · 20분)

  1. 문의 목록을 열어요. 오래된 순으로 봐요.
  2. 먼저 출고를 막아야 하는 문의만 골라내요. (취소, 주소변경, 수량변경)
    • 해당 송장이 이미 출력되고 포장까지 끝났으면 → 그 박스를 따로 분류해 둬요.
  3. 나머지 문의를 하나씩 답해요. 답할 수 있는 것만 답해요.
    • 입고 여부·재고 수량 → 재고내역 확인 후 숫자로 답하기 ("A023님, 수분크림 5개 입고·검수 완료됐어요")
    • 발송 여부 → 송장번호로 답하기
    • 파손·불량 → 검수 때 찍은 사진을 첨부해서 답하기 (📷 답변 사진 첨부 메뉴)
  4. 혼자 답하면 안 되는 문의는 답하지 않고 보고 목록에 적어요.
    • 환불·보상·무료 재발송 / 물류사고(오배송) / 판단이 애매한 것 / 수강생 민원이 생길 수 있는 것
  5. 처리 건수와 보류 건수를 세서 마감 보고에 적어요.
  6. 15:20이 되면 남은 문의에는 먼저 "확인 후 택배 포장이 끝나면 답변드리겠습니다"라고 답해요.
    • 그다음 운송장 2차 출력 → 택배 포장을 먼저 해요.
    • 남은 문의는 스토어 운영 시간(16:50~)에 가장 먼저, 그날 안에 반드시 답해요.

CS에서 하지 말 것

  • 아침·점심·저녁 수시로 문의 확인하기
  • 답장 쓰다가 포장 시간 넘기기

⑦ 남은 CS 답변 + 스토어 운영 (16:50–17:30)

15:20에 "포장 끝나고 답변드리겠습니다"라고 해 둔 남은 CS부터 답해요. 그다음 스토어 운영은 품절 처리 → 재고 들어온 상품 판매 재개 → 신규 등록 → 가격 점검 순서로 해요. 포장이 200건에 못 미쳤다면 포장을 먼저 끝내고, 스토어 업무는 보고에 "못 함"으로 적어요.

⑧ 뒷정리 + 내일 부자재 준비 (17:30–17:50)

4. 꼭 지키는 원칙 6가지

  1. 이 순서대로만 움직여요. 순서를 바꿔야 하면 먼저 알려 주세요.
  2. 매뉴얼에 없거나 애매한 일은 진행하지 말고 적어 둔 뒤 다음 일로 넘어가요.
  3. 한 번 만지면 끝까지 처리해요. 두 번 보면 시간이 두 배가 돼요.
  4. 같은 일은 몰아서 해요. CS·송장 출력·포장을 하루 종일 오가지 않아요.
  5. 밀리면 30분 안에 알려요. 예: 검수가 11:10을 넘길 것 같으면 그때 바로 말해요.
  6. 숫자로 말해요. "바빴어요" 대신 "200건 중 195건 출고, 5건 재고 없음"처럼요.

5. 상황별 대처

상황이렇게 해요
입고 박스가 100개를 훨씬 넘을 때오전에는 100박스까지만 검수하고, 나머지 박스는 스토어 운영 시간(16:50~)에 해요. 아침 보고에 미리 알려요.
주문이 200건을 넘을 때 (주로 월·화)스토어 운영 시간을 포장에 써요. 정해진 시간에 운영이 불가할 경우 미리 상황을 공유해요.
재고가 부족해서 못 나갈 때오류 송장을 따로 분류해서 먼저 보고하고, 포장이 끝난 뒤 상품명·주문 수량·실제 재고를 확인해 보고에 적어요.
취소·주소변경 문의이미 출력·포장이 끝난 건은 따로 분류해 둬요. 15:00 CS 때 처리하고 보고에 적어요.
파손·불량 입고사진을 찍고 따로 보관한 뒤 보고에 적어요. 입고 처리는 정상 수량만 해요.
계획보다 늦어질 때늦어진 단계와 이유를 적어 두고, 30분 이상 밀리면 바로 알려요.

6. 마감 보고 (매일 17:50)

어디에 적나요?

택배관리 시트 📝물류일일보고 탭의 오늘 양식 B. 마감 보고 칸에 적어요. 아래 양식·예시는 적는 방법을 보여 주는 참고용이에요. (8번 참고)

작성 원칙 — 숫자는 꼭 적고, 문장은 짧게 써요. 문제가 있었던 일은 무엇이 / 왜 / 내일 어떻게를 한 줄씩 적어요. 문제가 없던 항목은 "이상 없음"만 적어도 돼요.

8. 매일 보고 적는 법 — 택배관리 시트

아침 보고, 업무 시간 기록, 마감 보고는 모두 택배관리 시트의 📝물류일일보고 탭에 적어요. 하루에 양식 1장이고, 대표가 같은 양식에 피드백을 남겨요.

칸 색깔누가
노란 칸담당자가 적어요
파란 칸대표가 확인하고 피드백을 적어요 (담당자는 고치지 않아요)

① 출근하면 (09:00)

  1. 택배관리 시트를 열어요.
  2. 위쪽 메뉴 📦 택배관리 → 📝 오늘 물류보고 양식 만들기를 눌러요.
  3. 📝물류일일보고 탭 맨 위에 오늘 날짜 양식이 생겨요. 어제 양식은 바로 아래로 내려가요.
  4. 어제 양식의 파란 칸(대표 피드백)을 먼저 읽어요. 고칠 점이 있으면 오늘 바로 반영해요.
  5. 09:10까지 아침 보고 칸에 3줄로 적어요. (입고 박스 / 어제 미발송 / 특이사항)

② 일하는 중 (09:10–17:50)

  1. 업무 하나가 끝날 때마다 A. 업무 시간 기록표에 적어요.
    • 실제 시작~끝: 예) 09:10–10:55
    • 처리량: 예) 42/100박스, 120/125건
    • 이유 / 메모: 계획보다 늦었을 때만 짧게
  2. 몰아서 퇴근 전에 적지 않아요. 끝날 때마다 바로 적어요.

③ 퇴근 전 (17:50–18:00)

  1. B. 마감 보고 7칸을 채워요. 각 칸 왼쪽의 작은 글씨가 적는 방법이에요. (6번 예시 참고)
  2. 문제가 없던 칸은 "이상 없음"이라고 적어요. 빈칸으로 두지 않아요.
  3. 다 채우면 퇴근해요.

하지 말 것

  • 파란 칸(대표 피드백) 고치거나 지우기
  • 지난 날짜 양식 지우기
  • 메뉴를 여러 번 눌러 같은 날 양식을 여러 장 만들기 (한 번만 누르면 돼요)

대표 확인 방법

메뉴 📦 택배관리 → 📝 물류보고 탭 열기 → 맨 위 양식의 파란 칸에 항목별 피드백을 적고, C. 대표 종합 피드백에서 확인 칸을 체크하고 한마디를 남겨요.
